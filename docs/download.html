Apply Tool for Linux

For Linux x86_64. Install Flatpak first, then open the installer in your software manager.

Install Apply Tool · GitHub releases

flatpak install --user https://trifazor.github.io/apply_tool/apply-tool.flatpakref
flatpak run io.github.trifazor.ApplyTool
flatpak update --user

The app comes from our signed repository. Its GNOME runtime comes from Flathub. Install and authenticate Claude Code, Codex or OpenCode on your computer to use AI generation. Typst and Pandoc are included.

Updates are available through your software manager or flatpak update. Automatic installation depends on your desktop settings. Updating preserves your documents and settings in ~/ApplyTool.
